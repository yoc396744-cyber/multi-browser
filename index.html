匯入登入：

Google 會擋這類內嵌瀏覽器登入，所以改成在一般瀏覽器登入，再把遊戲的登入 cookie 帶進來：

  1. 用 Chrome 或 Edge 開無痕視窗（Ctrl+Shift+N），到遊戲網站用 Google 登入
  2. 登入後按 F12 → 切到「Network / 網路」分頁 → 按 F5 重新整理
  3. 在清單找到 me 那一筆 → 按右鍵 → Copy → Copy as cURL (bash) → 整段貼到下面
    （或點 me → Headers → Request Headers 裡的 Cookie，複製那一串值）
  4. 匯入成功後直接關掉無痕視窗（不要按登出，登出會讓這組登入失效）
