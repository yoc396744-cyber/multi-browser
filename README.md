# 多帳號瀏覽器（RO放置仙境）

在同一個畫面同時開多個 [RO放置仙境](https://ro-idle.app/) 視窗，每個視窗各自登入不同帳號，而且全部保持在前景運作。

## 安裝與啟動

1. 安裝 [Node.js](https://nodejs.org/)（LTS 版）
2. 下載這個專案：
   ```
   git clone <這個專案的網址>
   ```
3. 雙擊 `start.bat`（第一次會自動下載 Electron，要等一兩分鐘）

更新到最新版：在專案資料夾執行 `git pull`，然後重開 `start.bat`。

## 功能

- **多帳號**：每個視窗的登入資料各自獨立，按「＋ 新增視窗」就能多開一個
- **📊 總覽**：上方表格列出所有角色的等級、負重、Zeny、屬性點等資料；可以切到「只看總覽」，把遊戲畫面縮起來
- **顯示模式**：每個視窗可以切換「完整 / 精簡 / 僅統計」
- **排版**：可以選欄數，或用「單排」模式左右捲動；拖曳視窗左上角的握把可以調整順序；「顯示」可以只放大其中一個帳號
- **倉庫小幫手**：一次領出多樣道具（可設定領出後自動賣掉）、從背包一次存入、搜尋、全選
- **自動精煉**：視窗上方的精煉按鈕。級數一、二的金屬會自動購買；神之金屬和鋁會從倉庫領（原石不會領）
- **交易搬移**（倉庫小幫手的「交易搬移」分頁）：把倉庫的東西透過交易搬到別的帳號。送出方勾選要搬的品項（設定會記住），自動從倉庫領出、一筆最多 10 項交易過去，重複到搬完；接收方自動接受指定角色的交易並存入倉庫。兩個角色要在同一座有卡普拉的城鎮、都停止掛機

## Google 帳號登入

Google 會擋內嵌瀏覽器的登入，所以要改用「匯入登入」：在一般瀏覽器的無痕視窗用 Google 登入遊戲，再把 cookie 貼進來。詳細步驟在視窗上方的「匯入登入」按鈕裡。

## 注意

- 自動精煉會真的花 Zeny，超過安全精煉值失敗時裝備會損壞
- 登入資料存在 `%APPDATA%\multi-browser`，不在專案資料夾裡。不要把這個資料夾傳給別人
